Automatische Kursbuchung

Freischaltung 5 Tage vor Kursbeginn, gebucht wird 2 Sekunden danach. Änderungen hier landen direkt in deinem GitHub-Projekt.

Einmal einrichten

Die App braucht einen GitHub-Schlüssel, um dein Buchungsprojekt ändern zu dürfen. Er wird nur in diesem Browser gespeichert.

  1. Öffne github.com/settings/personal-access-tokens/new
  2. Name: Buchungsapp · Ablauf: 366 days
  3. Repository access: Only select repositories → buchung-automatik
  4. Permissions → Add permissions: Actions, Contents und Workflows, jeweils auf Read and write
  5. Generate token, den Schlüssel kopieren und hier einfügen.
